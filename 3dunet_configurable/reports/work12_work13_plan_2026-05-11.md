## 161:160 Downscale mi?

Hayir. `161:160`, APBS kaynak gridinin dogal temsilidir.

APBS kaynak grid:

```text
161 x 161 x 161 points
160 A physical span
1.0 A spacing
```

Target grid `161:160` ise:

```text
161 x 161 x 161 points
160 A physical span
1.0 A spacing
```

Bu durumda downscale yoktur. Hedef grid APBS gridine ayni nokta sayisi ve ayni fiziksel span ile denk gelir. Kod yine genel resample fonksiyonundan gecer, ama center/origin uyumluysa veri efektif olarak 1 A gridde kalir.

Asil downsample olanlar:

```text
72:160  -> 1 A APBS gridinden 2.2535 A spacing'e iner.
36:160  -> 1 A APBS gridinden 4.5714 A spacing'e iner; pocket detayi icin fazla kaba olabilir.
```

`36:70` farkli bir durumdur:

```text
36 x 36 x 36
70 A span
2.0 A spacing
```

Bu, APBS'in 160 A kaynak alanindan protein merkezli daha kucuk bir hedef alana resample/crop yapar. Kalasanty/PUResNet tarzina daha yakin hizli grid olarak anlamlidir, ama coverage mutlaka kontrol edilmelidir.

## Work12 - Folded 36/72/161 Codon Training

Durum: Work11 full cache tamamlandiktan sonra baslatilacak.

Amac: 36, 72 ve 161 grid boyutlarinda folded training yapip APBS katkisini ve grid cozumurlugu etkisini guvenilir olcmek.

Default grid matrix:

```text
36:70
72:160
161:160
```

Ilk onerilen kapsam:

```text
5 folds
primary dataset: scPDB cavity6, include-all-labels cache
secondary dataset: PDBBind, label protocol separately reported
```

Fold kurali:

- scPDB icin ayni base PDB id farkli foldlara dagitilmamali.
- Ornek: `1abc_1`, `1abc_2`, `1abc_3` ayni fold grubunda kalmali.
- Mumkunse sequence/complex redundancy de sonra kontrol edilmeli.

Coverage kurali:

- Her grid size icin manifest uzerinden `dataset_label_atoms_in_box / dataset_label_atoms` kontrol edilmeli.
- 36:70 icin label coverage dusuk case'ler ya filtrelenmeli ya da ayri raporlanmali.
- 72:160 ve 161:160 icin full protein/label coverage beklenir; beklenmiyorsa cache veya centering tekrar incelenmeli.

Minimal ama guclu training matrisi:

| Grup | Feature set | Model |
|---|---|---|
| A | apbs_only | ResNet3D4L |
| B | shape_only | ResNet3D4L |
| C | apbs_shape | ResNet3D4L |
| D | shape_selected_chem | ResNet3D4L |
| E | apbs_shape_selected_chem | ResNet3D4L |

Bu matris:

```text
3 grid sizes x 5 feature sets x 5 folds = 75 trainings
```

Eger bu cok agir olursa once:

```text
36:70 + 72:160 full 5 folds
161:160 sadece en iyi 2-3 feature set
```

seklinde iki asamaya bolunmeli.

Opsiyonel ikinci model kontrolu:

```text
ResNet3D4LGN
UNet3D4LA
```

Bunlar tum matrise degil, sadece en iyi 1-2 feature set icin kosulmali.

Work12 raporunda mutlaka olacak metrikler:

- Fixed-threshold voxel-F1.
- Validation-selected threshold.
- Pocket-F1 / DCC@4A.
- Top-1 DCC@4A.
- Top-3 DCC@4A.
- DCA@4A.
- DVO_all.
- DVO_DCC_success.
- Mean predicted pocket size.
- No-prediction count.
- Per-fold mean/std.

Threshold protokolu:

- Test/fold reporting icin threshold test setinde optimize edilmemeli.
- Her fold threshold'u kendi validation split'inden secilmeli.
- Final deploy threshold'u fold threshold'larinin median'i veya final held-out calibration threshold'u olmali.
